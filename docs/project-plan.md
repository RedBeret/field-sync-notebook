# Field Sync Notebook Plan

## Product Positioning

Build a credible offline-first workspace that helps operators and engineers keep notes, tasks, and attachments moving even when connectivity is poor.

## Core User Story

An engineer or operator needs to:

1. Record what happened now, not later
2. Track what still needs follow-up
3. Keep work visible across a shift handoff
4. Sync cleanly once connectivity recovers

## Why This Project Fits The Portfolio

This project adds a strong disconnected-workflow story to the portfolio:

- offline-first UX
- task and note handoff
- sync-state reasoning
- conflict-aware product design

## MVP Scope

- workspace catalog
- note and task queue
- connection mode toggle
- sync preview and result summary
- attachment and conflict views
